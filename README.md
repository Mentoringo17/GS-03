# 🧬  Виртуальная разработка лекарства от глиобластомы

##  Автор: Mentoringo
## 📅 Период исследования: 08.10.2026 – 13.11.2026

## 🎯 О проекте
Этот проект посвящен разработке молекулы-кандидата **GS-03** для таргетной терапии глиобластомы. С помощью методов компьютерного моделирования (in silico) мы спроектировали молекулу, которая способна проходить через гематоэнцефалический барьер (ГЭБ) и связываться с мутантным белком EGFRvIII.

## 🧪 Результаты
- **Молекула:** GS-03 (SMILES: `O=C(Nc1ccccc1OC)c2cc(F)ccc2N`)
- **Брутто-формула:** C14H13FNO2
- **Молекулярная масса:** 260.3 Да
- **Энергия связывания (докинг):** -4.00 ккал/моль
- **Проверки:** Пройдены тесты Липински (токсикология) и ГЭБ (проходимость в мозг).
- **Синтез:** Разработан синтетический маршрут из 2 стадий.

## 🛠 Использованные технологии
- Python 3
- Библиотеки: RDKit, Biopython, NumPy, Py3Dmol
- Среда: Google Colab, Sublime Text
