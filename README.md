Этот проект посвящен разработке молекулы-кандидата **GS-03** для таргетной терапии глиобластомы. С помощью методов компьютерного моделирования (in silico) мы спроектировали молекулу, которая способна проходить через гематоэнцефалический барьер (ГЭБ) и связываться с мутантным белком EGFRvIII.

## 1. ВВЕДЕНИЕ
**Актуальность темы:** Глиобластома — одна из самых агрессивных форм рака головного мозга. Главная проблема в её лечении — гематоэнцефалический барьер (ГЭБ), который не пропускает 98% лекарств. Кроме того, опухоль часто имеет мутацию EGFRvIII, заставляющую клетки делиться бесконечно.

**Цель работы:** Создать виртуальную модель молекулы (GS-03), которая сможет преодолеть ГЭБ, связаться с белком EGFRvIII и заблокировать его, будучи безопасной и простой в синтезе.

**Задачи:**
1. Изучить структуру белка-мишени и найти его «карман».
2. Спроектировать молекулу для связывания с белком.
3. Проверить молекулу на безопасность и проходимость через ГЭБ.
4. Разработать синтетический маршрут (рецепт) для химиков.

---

## 2. ТЕОРЕТИЧЕСКАЯ ЧАСТЬ
**2.1. Мутация EGFRvIII:** В гене EGFR происходит делеция (потеря) экзонов 2-7. Белок становится «всегда включенным», клетка делится без остановки.

**2.2. Проблема ГЭБ:** Чтобы лекарство прошло в мозг, оно должно быть маленьким (до 500 Да) и жирорастворимым. Для улучшения проходимости использован принцип «Троянского коня» (маскировка под питательные вещества).

## 4. РЕЗУЛЬТАТЫ И ИХ ОБСУЖДЕНИЕ
**4.1. Анализ структуры белка:** Скачана структура EGFR (ID: 1IVO), очищена от воды и лигандов. Вычислен геометрический центр кармана (X=83.77, Y=56.31, Z=50.23). 

**4.2. Дизайн и оптимизация молекулы:**
- **GS-01:** Энергия связывания -2.90 ккал/моль.
- **GS-02 (с фтором):** Улучшение до **-4.00 ккал/моль**.
- **GS-03 (финальная):** Замена гидроксила (-OH) на метокси-группу (-OCH3) для прохождения ГЭБ.

**4.3. Свойства GS-03 (Паспорт молекулы):**
- **SMILES:** `O=C(Nc1ccccc1OC)c2cc(F)ccc2N`
- **Формула:** C14H13FNO2
- **Масса:** 260.3 Да.
- **LogP:** 2.67.
- **TPSA:** 64.3.
*Молекула полностью соответствует правилу Липински и имеет высокий профиль безопасности.*

**4.4. Синтетический маршрут:** Молекула собирается за 2 стадии методом амидирования из доступных реагентов (3-фторбензойная кислота + 2-аминофенол). Условия: комнатная температура, катализатор EDC/NHS, растворитель DMF. Без взрывоопасных реагентов.
